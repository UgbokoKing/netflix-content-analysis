# Netflix Movies & TV Shows Analysis

## Project Overview
This project explores Netflix's content library to uncover insights 
regarding content types, distribution, and release patterns. As streaming 
platforms continue to dominate the entertainment industry, understanding 
how content strategies shift over time is critical.

## Dataset
[Netflix Movies and TV Shows (Kaggle)](https://www.kaggle.com/datasets/shivamb/netflix-shows)
- 8,807 rows × 12 columns
- Source: Kaggle (Shivam Bansal)

## Key Findings
- **Content Split:** Netflix's catalog is ~70% Movies (6,131) and ~30% TV Shows (2,676)
- **Recent Push:** The majority of content falls in the "Recent" era (2015+), 
  reflecting Netflix's aggressive content acquisition strategy
- **TV Shows are newer:** Average release year for TV Shows (2016.6) is 
  notably more recent than Movies (2013.1)
- **Top producing country:** United States dominates Netflix's content library
